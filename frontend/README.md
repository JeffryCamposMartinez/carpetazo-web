# Carpetazo — Frontend

React 19 + Vite + Tailwind. Ver el README de la raíz para el proyecto completo y `CLAUDE.md` para dónde va cada cosa.

```bash
npm install
npm run dev      # http://localhost:5173 (envía /api a localhost:8000)
npm run build    # build de producción + páginas legales prerenderizadas
```

Estructura de `src/`: `app/` (rutas), `pages/`, `components/<tema>/`, `contexts/`, `services/`, `config/`, `utils/`, `legal/`.
